# StudyFlow Phase 2 – Upload-ready prototype

## Files
- `index.html` – page structure and interface
- `style.css` – layout, colours, responsive styling and accessibility focus states
- `app.js` – task planner, learning quiz, progress, reminders, backup/import and theme behaviour

## Run locally
Open `index.html` in a modern browser. No server or installation is required.

## Publish as a link
This folder can be uploaded to a static web host. For GitHub Pages, create a repository, upload these three files to the repository root, then enable Pages from the repository's Settings. The published site will receive a shareable `github.io` address.

## Prototype limitations
This is a front-end prototype. Data is held in browser memory and reload resets changes. JSON backup/import is manual. There is no authentication, live reminder delivery, Moodle connection or backend.
