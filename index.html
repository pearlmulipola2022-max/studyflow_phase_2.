LEARNING

HCI practice

Objective

Explain why usability testing and user feedback matter when refining an interface.

Content

Usability testing observes representative users completing realistic tasks. Useful evidence includes completion, errors, time, help requests, ease ratings, and comments. Findings should be linked to design changes and, where possible, retested.

Example: If users repeatedly miss the save confirmation, improve feedback and verify the change with another test.
